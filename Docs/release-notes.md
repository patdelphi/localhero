# 发布说明 1.0.0

- 发布日期：2026-11-06
- 对应阶段：第十三阶段「产品化与部署」
- 测试规模：189 项全部通过

## 新增

- 一键启动脚本 `start.ps1` 与 `start.bat`，支持开发/生产配置档。
- 开发档默认离线模拟，`-Offline` 可在任何配置档强制离线。
- 结构化 JSON 日志：`data/logs/app.jsonl`，自动滚动。
- Provider 调用统计：请求数、最终失败数、本地回退数、累计与最近耗时。
- 健康接口扩展：schema 版本、数据库状态、离线模式与调用统计。
- 存档在线备份、完整性检查、确认式恢复与安全副本。
- 单存档 JSON 导出/导入，命令行与 API 均支持。
- `.env.example` 与部署文档。

## 变更

- `requirements.txt` 显式声明 `httpx`，生产安装不再依赖开发依赖。
- 应用版本号更新为 `1.0.0`。
- 分支重建与导出导入复用同一确定性前缀重放逻辑。

## 升级注意

- schema 仍为 v8；首次启动会自动迁移旧库，并在迁移前生成 `pre-v*` 备份。
- 真实 `data/games.db` 已在 2026-11-06 由 v7 迁移至 v8，迁移前保留 `pre-v8` 备份与独立备份。旧档缺少 v5 基线，回放按设计返回 `baseline_missing`。
- 恢复存档会覆盖当前库，必须先停止服务并确认。

## 安全

- 密钥仅从环境变量读取，不进入存档、日志、健康接口或导出文件。
- 默认监听 `127.0.0.1`。
- 恢复必须显式 `--confirm`，且自动保留当前库副本。

## 已知限制

- 仅面向本机单用户，不做公网多租户、计费或运营后台。
- 不做实时多人协作与云端同步。
- 在线 Provider 需兼容 OpenAI Chat Completions。
