# 蜂巢区详细地点

## 区域质感

蜂巢区不是贫民窟，而是被高度设计过的可负担生活。道路平整、指示清楚、公共服务集中，楼间有顶步道在雨天十分方便。居民的不满往往来自细小的权限：一扇门要求重新验证、一个电梯不再夜间停靠、共享厨房把某户识别为超额。这里的声音以通风、门禁提示、配送车和楼层群消息为主，夜里仍有大量灯光，因为许多人的工作不按白天结束。

## HC-01 栖光里商业综合体

- **坐标**：`(5.2, 1.4)`。
- **定位**：服务周边十二栋住宅与通勤者的六层综合体，地上四层、地下两层。
- **经营者**：安澜商业运营部，物业服务由同集团另一团队负责，安保外包。
- **外观与感官**：入口是巨大的浅木色雨棚，实际墙面多为耐用复合板。中庭有烘焙、清洁剂和人群气味，提示音始终温柔，即使内容是权限拒绝。
- **公共入口**：西侧连接生活环，南侧连接换乘步道。
- **后勤入口**：东北卸货区，商户、垃圾、配送机器人与员工使用。
- **应急通道**：四周楼梯和地下防火分区，顾北庭有有限手动权限。

### B2：设备、停车与卸货

- **能源与水泵间**：顾北庭团队管理，有实体阀门、隔离控制柜和纸质检修表。
- **配送机器人区**：循光小型配送车充电、清洁和异常等待，夜班远程接管员通过工位处理。
- **商户卸货口**：按预约时段分配，迟到会失去排位，小商户对此抱怨最多。
- **垃圾分拣间**：自动识别错误会转化为商户罚款，清洁工可人工更正但流程复杂。

### B1：平价生活与维修

| 商户 | 商品或服务 | 经营特点与剧情用途 |
|---|---|---|
| 六点半便利 | 全天食品、药品外带和缴费 | 夜班工聚集地，保存短时公共区域录像 |
| 回针维修 | 终端换屏、电池和小家电 | 梁九认识的同行，正规维修与灰色解锁界线清楚但常被客户要求越界 |
| 日日剪 | 快剪、简单护理 | 不强制会员，理发师知道许多楼层消息 |
| 纸鹤打印 | 材料打印、扫描、来源见证 | 人工复核者常用，店长会要求本人确认敏感文件 |
| 换季仓 | 二手衣物、家具和搬家寄卖 | 人员流动的生活痕迹，可寻找前住户物品 |
| 好眠洗衣 | 大件洗涤和夜班自助柜 | 取件码和柜体记录可证明时间，免费账户保存期短 |

### L1：餐饮与主入口

| 商户 | 商品或服务 | 特点 |
|---|---|---|
| 潮汐食堂 | 标准套餐、早餐与夜班饭 | 自动烹饪，仍由厨师处理异常和口味 |
| 半勺咖啡 | 咖啡、安静座位和共享电源 | 自由职业者与外包员工办公，禁止长时间占用面试舱 |
| 鸥面包房 | 烘焙、预订蛋糕 | 用本地面团和中央配方，店内香味是综合体营销一部分 |
| 北岸辣铺 | 港口风味干锅和面食 | 工人家庭聚餐点，晚市喧闹 |
| 青禾轻食 | 营养模型配餐 | 可读取健康授权，许多顾客不知道默认授权范围 |
| 两杯茶 | 茶饮、楼层拼单 | 周弥等配送员常在此等单，店员熟悉平台路线变化 |

L1 另有访客服务台、人工物业投诉窗口和一面“今日运行良好”的公共屏。屏幕只显示已关闭工单，不显示尚未受理的投诉。

### L2：健康、教育与公共服务

- **澜生轻诊**：慢病复诊、康复评估和义体基础校准，不能处理重大急救。
- **松果药房**：处方药与常用药，夜间药师远程值班，人工取药仍需本地核验。
- **同桌学习室**：儿童托管、成人培训和真人答疑，乔稚偶尔做公益课程。
- **蜂巢政务角**：身份、劳动与住房自助终端，只有固定时段有真人支援。
- **同舟服务亭**：保险销售和理赔材料扫描，复杂拒赔被转去云顶。

### L3：休闲、社群与住户服务

- **折线书屋**：独立书店兼小放映厅，卖纸质书、杂志和本地调查报告，是折线媒体的社区合作点。
- **肉身在场排练室**：现场戏剧、音乐和即兴表演，按时收费，晚间隔音一般。
- **共同厨房**：可预约烹饪与拼饭，能耗、清洁和食物来源均被记录。
- **住户议事厅**：居民委员会、家长会和物业听证使用，录像是否公开每次争论。
- **小憩舱**：按小时休息，夜班劳动者使用多，超时费用高。

### L4：办公与限制区域

- 安澜商业运营办公室、物业客服、商户会议室外包安保值班室。
- 顾北庭不常驻此处，其工程调度点在邻近连廊。
- 数据间只保存综合体本地缓存，不是整个蜂巢的中央大脑；入侵这里仍无法直接控制所有住宅。

### 日常事件与隐藏用途

早高峰早餐与通勤，中午基层职员用餐，傍晚家长和孩子进入 L2，深夜 B1 与 L1 仍有生活。综合体常把住户议事厅用于安排“协商”，但议题和时间由物业控制。后勤区则能看到宣传中消失的大量人工劳动。

## HC-02 蜂巢七号楼

- **坐标**：`(4.8, 2.1)`。
- **定位**：三十二层保障房，约 1900 名居民，2055 年能源配给事故发生地。
- **管理者**：安澜保障房运营部，顾北庭负责片区工程而非专职七号楼。
- **住户**：平台劳动者、老人、基层职员、拼户家庭和短期项目工。

### 楼层结构

- **L1**：门禁、快递柜、住户服务台和无障碍坡道。大厅保留长椅，源于 2050 年门禁故障时居民露宿。
- **L2—L9**：微型间和合租单元，租户流动快，外卖和配送纠纷多。
- **L10**：公共活动层，共享厨房、洗衣、儿童角和避暑区。
- **L11—L22**：标准单人及双人单元，以年轻家庭为主。
- **L23**：第二公共层，老人日间活动和社区护理站。
- **L24—L30**：较大单元，部分按人才公寓价格出租，住户对保障资源分配有意见。
- **L31—L32**：设备层与少量高区住宅，水泵、通风和太阳能控制位于此。
- **屋顶**：通信、天线和检修区，不对居民开放。

### 系统与手动控制

门禁、电梯和能源各自有控制柜，物业模型统一建议但不应全部直接执行。夜间低峰策略可能减少电梯，工程端可临时恢复。每次手动旁路都会生成记录，顾北庭无法无限次无痕操作。

### 社区生态

楼层群替代部分邻里关系，消息快、谣言也快。十层拼饭群、二十三层老人互助和低层夜班群各自形成规则。有人用私人代理过滤物业通知，因而错过人工申诉期限。

### 可玩矛盾

能源恢复应先供医疗设备、整楼水泵还是商业冷柜；公开事故日志能证明总部策略，也会显示具体住户用电和健康状况。居民并非统一要求全面公开。

## HC-03 栖光里社区学校

- **坐标**：`(5.8, 2.4)`。
- **类型**：九年一贯制公立学校，约 1200 名学生。
- **管理者**：校长负责行政，区教育局提供教学代理，安澜负责建筑物业。
- **感官**：午餐、纸张和消毒水味，课间是孩子声音而非提示音；校门的人脸核验常与家长接送代理不同步。

### 分区

- **低年级楼**：教室、午休区和家长接待。
- **高年级楼**：实验室、讨论室和作品档案室。
- **媒介素养教室**：乔稚主要教学空间，终端可切为无代理模式。
- **运动场**：与社区错时共享，晚间由物业门禁管理。
- **数据与档案室**：保存本地缓存和纸质事故记录，不长期存全部学生模型数据。
- **后勤门**：餐饮、清洁和维修使用，连接综合体生活环。

### 日常矛盾

家长希望教学代理提高成绩，又反对孩子被持续画像。教师可以临时关闭推荐，却要承担成绩和课堂管理压力。乔稚推动的学生画像查阅机制，需要家长、学校与区教育局共同参与，不能只靠她开放一个文件。

## HC-04 零工互助站

- **坐标**：`(4.5, 1.0)`。
- **外观**：由两个旧商铺打通，没有醒目标牌，门口贴着充电价格、法律援助时间和失物招领。
- **运营**：周弥和轮班志愿者，资金来自成员小额会费与公益捐助。
- **感官**：雨衣、电池、泡面和打印机味，夜里总有人进出。

### 分区

- **充电与休息区**：符合安全标准的电池柜、躺椅和饮水。
- **证据工位**：旧电脑、离线硬盘和共享扫描仪，成员可导出封号、路线与工资记录。
- **小会议室**：用于讨论集体行动，容不下所有成员，因此决策常被指责由少数人控制。
- **物资柜**：雨具、简易药、备用终端和法律援助表格。
- **后间**：周弥临时存放个人物品，不是秘密总部。

### 日常事件

有人刚被封号来求助，有人争论是否罢工，有人只来睡觉。互助站保存的证据很有价值，但成员授权标准不统一，玩家不能拿走整库数据。周弥必须在集体筹码和个人同意之间做选择。

## HC-05 蜂巢派出所

- **坐标**：`(5.5, 0.8)`。
- **特点**：处理的案件更偏身份、平台诈骗、物业冲突与网络犯罪，社区关系不如旧城区稳定。
- **分区**：自助报案区、人工窗口、调解室、网安联络工位和临时等候区。
- **出入口**：公众正门与物流侧门分开，晚高峰门前经常挤满来报案的配送员。

派出所和物业有联动渠道，容易让居民认为物业能决定警方优先级。实际上双方只是共享部分安全风险信息，个别警员是否过度依赖物业才是问题。玩家若从旧城区带来案件，需要明确管辖与证据移交，不能假设罗启明能直接指挥这里。

## HC-06 蜂巢换乘枢纽

- **坐标**：`(5.0, 0.4)`。
- **结构**：地铁一号线与四号线、公交层、出租车站、配送等候区和有顶步道。
- **使用者**：跨区通勤者、配送员、学生和前往云顶的外包工。
- **感官**：轮胎、雨水和快餐味，导航提示密集，早晚人流方向明显。

### 细分

- **B1 地铁层**：安检、站台与设备区，灰档者可能在闸机被拦。
- **L1 公交与步行层**：人工服务亭、失物招领和公共屏。
- **L2 生活环连接层**：商店、早餐摊、共享雨具和配送等候。
- **北侧配送区**：机器人与人工车辆分流，路线调整会直接影响周弥收入。

枢纽是观察跨区阶层的好地方：同一站台上有去云顶的高管、外包清洁员和夜班护理员，他们下车后进入完全不同的门。

## HC-07 新栖公寓

- **坐标**：`(6.3, 1.7)`。
- **定位**：由旧产业宿舍楼改造的青年公寓，租金略低于新建蜂巢楼，隔音和维护较差。
- **运营**：小型物业公司接入安澜部分系统，规则不统一。
- **住户**：方笙、数据清洁员、内容审核员、新来城市的培训生。

### 分区

- **公共大厅**：快递架、旧售货机和项目招聘广告。
- **标准单元**：床、桌、小卫浴和简易厨台，窗帘常全天关闭以适应夜班。
- **公共网络间**：居民自购中继设备，稳定但安全管理混乱。
- **屋顶晾衣区**：夜班工白天休息，傍晚才有人活动。
- **地下储物层**：搬家者遗留物品和未登记隔断，消防隐患明显。

方笙的房间保存多份离线备份和纸质票据，桌上分颜色贴着不同项目标签。她的生活空间能证明劳动强度，也包含同事与客户的敏感资料，不能简单搜走。

## HC-08 断电工坊

- **坐标**：`(4.4, 0.2)`。
- **外观**：旧车库改造，门口只写“断电之后再说话”，卷帘门常放下一半。
- **经营**：韩鹭与一名不常出现的二手设备中间人共用空间，前者做隐私改装和取证，后者负责货源。
- **感官**：热风、金属和旧电子元件气味，设备启动声此起彼伏。

### 分区

- **前厅二手区**：展示已清除数据的终端、哑机和离线代理盒。
- **隔离工位**：无公网，只有明确允许的物理连接，用于检查恶意样本。
- **屏蔽柜**：存放客户设备与待鉴定模块，不是绝对安全，只是降低无线风险。
- **阁楼休息处**：韩鹭偶尔过夜，有即食食品和魏淑珍送的旧毛毯。
- **后巷门**：设备中间人送货使用，缺乏正式装卸区。

工坊能提供强大技术支持，也是一把双刃剑：任何接入设备都可能被复制，韩鹭若认为客户隐瞒风险，可能先保留证据再解释。玩家需要与她约定范围，而不是默认她只执行命令。

## HC-09 安澜工程调度点

- **坐标**：`(4.9, 1.5)`，栖光里西侧连廊。
- **负责人**：顾北庭，与白班和夜班工程组共用。
- **功能**：处理楼栋工单、手动降级、备件和现场协调。
- **区域**：值班室、工单墙、备件间、本地控制间和员工小休息室。

### 关键细节

工单墙用红、黄、白区分安全、居住影响和一般便利，总部面板则按成本与超时排序，两种顺序常冲突。本地控制间保存短期手动日志，完整历史同步总部。顾北庭的 2055 指令副本不放在公司终端，而藏在一台退役检修机的离线存储中。

工程组是居民最容易找到的真人，却也是总部压力的直接承受者。夜班里常能看到他们边吃冷饭边处理十几栋楼的问题。

## HC-10 蜂巢公共医疗站

- **坐标**：`(6.0, 0.7)`。
- **类型**：公立基层医疗与夜间转诊点。
- **服务**：分诊、慢病、简单处置、职业劳损和急救转运。
- **分区**：自助预检、人工挂号、两间诊室、处置室、观察区和救护通道。

分诊代理能缩短排队，却对方言、复杂病史和情绪表达处理较差。医疗站与青苔诊所互有转诊，林砚舟认识夜班医生。身份受限者在此可获急救，但后续药物和保险仍需处理，玩家可能需要在两区之间运送纸质证明。

## 小型补充地点

- **夜班拼饭厨房**：住户自营，按周轮班，最容易听到真实物业和劳动消息。
- **二十四小时自助仓**：搬家与项目流动者的物品中转，凭码取件，存在灰色代存。
- **公共电话亭**：为设备失效和紧急求助保留，使用率低但维护记录完整。
- **生活环广告廊**：本地商户和平台广告交替，文案会根据通行者账户变化。
- **儿童旧物交换角**：乔稚与家长维护，体现保障房社区不只有监控和欠费。

## 场景写作提示

蜂巢区的冲突应通过“标准化服务遇到例外”展开。不要让所有门禁同时失控，也不要把居民写成没有互助的原子。楼层群、拼饭、夜班、学校和家长会都能形成强关系，只是这些关系通常比旧城区更新、更快，也更容易随搬家和项目结束而中断。
