# 军事、警务、安保与城市冲突

## 安全格局

临潮不是战区。多数冲突表现为封门、跟踪、拘留、账号冻结、数据勒索、短时肢体冲突和可控威胁，而非每天街头枪战。真正危险的是不同力量都能把某一段系统当作武器：警察可以依法限制通行，物业可以限制电梯，平台可以停止派单，黑客可以让证词失去可信来源。

## 国家军队

宁洲共和国军由陆军、海军、空军、海防工程部队和网络防御司令部组成。军队负责国防、重大灾害和关键基础设施危机，不处理普通城市案件。临潮外海有海军与海警设施，新海堤在特大灾害时可由海防工程部队接管。

网络防御司令部保护军事、能源、金融和政务骨干。其 进攻 能力受到法律与保密约束，公众只知道少数行动。军队没有权限因普通黑客传言随意封锁全市，只有在宣布重大公共紧急状态后才可能扩大管制。

### 军队与城市的接触点

- 台风和海堤事故中的工程救援；
- 港口与海底电缆安全；
- 重大网络攻击后的基础设施恢复；
- 退役人员进入警察、企业安保和维修行业；
- 军民两用无人机、传感器和外骨骼流入受控民用市场。

## 临潮市公共安全局

### 分局体系

五区各设分局，旧城区与蜂巢区另设派出所和社区警务站。基层警察处理纠纷、盗窃、失踪和家庭危机，刑侦支队处理重大案件，网安支队处理入侵、身份犯罪与模型相关攻击。

### 主要专业部门

| 部门 | 职责 | 常见局限 |
|---|---|---|
| 社区警务 | 纠纷、巡查、重点人员与基层服务 | 熟悉街区但人手不足，容易依赖楼长和物业 |
| 刑事侦查 | 暴力、绑架、重大诈骗和死亡案件 | 资源优先投向高影响或高关注案件 |
| 网络安全支队 | 入侵、恶意代理、数据黑产和关键系统 | 技术强，但依赖企业提交日志与接口 |
| 身份犯罪组 | 宁证冒用、灰档犯罪和伪造记录 | 跨部门同步缓慢，受害者常先受限制 |
| 公共秩序处 | 集会、罢工和重大活动 | 可能把劳动争议视为秩序风险 |
| 应急联动组 | 与海防、消防、医疗协调 | 灾害时权限大，平时只负责预案 |

### 警务模型

模型用于报案分诊、视频检索、风险地点预测和案件材料整理。法律禁止仅凭风险评分定罪或实施长期监控，但评分会影响巡逻和核查频率。旧城区与蜂巢区因历史报案多而得到更多巡查，更多巡查又产生更多记录，形成自我强化。

警察个人可以不相信模型，却不能轻易忽略系统标记。忽略后若出事需承担责任，照模型行动则可在程序上免责。这种激励使“只按流程”成为理性选择。

### 罗启明式社区警察

社区警察真正依赖的是对人、楼和关系的认识。他们知道哪户有老人、哪个商户夜间营业、哪个青年只是替人跑腿。其保护能力来自信任，风险则是把熟悉当作客观、把不喜欢的居民视为麻烦。

## 企业安保

### 衡宇系统安保

重点是园区访问、数据泄露、模型供应链和人员审查。其网络防御能力强，实体安保偏向低风险制止、证据保存和警方移交。对前员工和承包商的数字权限追踪，比街头巡逻更有威慑力。

### 安澜置业物业安保

负责蜂巢住宅、商业综合体和更新项目。保安处理门禁、消防、冲突和夜间巡逻，权限受物业合同约束。部分外包保安同时接受风险模型排班，容易把被标记者当作天然可疑对象。其装备通常为防护背心、约束带、照明与非致命器械。

### 循光与港口安保

港口安全重视车辆、货物和工业控制区。安保有权限制进入生产区域，使用无人机和自动路障，但不能随意跨区追捕。灰色货物常通过合法单据、外包车辆和维修通道流动，而非硬闯武装卡口。

## 私人调查与灰区事务所

私人事务所在登记后可从事寻人、婚姻与民事调查、商业背景核验、调解和证据整理。无强制传唤、搜查和拘捕权。窃听、非法访问、冒充公务人员、私闯住宅均可能违法。

事务所的实际优势是能花时间处理低优先级案件，且不必完全按照部门边界思考。其信誉依赖两件事：是否兑现承诺，是否会把委托人的弱点卖给别人。白绳会、警察和企业都可能试图把事务所变成自己的眼线。

## 白绳会

白绳会起源于老港区货运互助与旧城区夜间看守，后来形成兼具保护、调解、借贷和犯罪的组织。成员不一定是职业暴徒，许多人白天有货运、修理或保安工作。其名字来自早期货车上识别互助车辆的白绳。

### 行为方式

- 收取协调费，提供夜间巡逻、纠纷调解和货物安全；
- 经营高息周转和非法搬运；
- 通过围堵、停工、跟踪和曝光隐私施压；
- 必要时使用棍棒、电击器或刀具，避免无准备枪战；
- 与社区商户、个别警察和更新承包商保持非正式交易。

白绳会不控制整个旧城区。它能影响某些街和夜间货运，却无法命令所有居民。其合法性来自“确实能解决问题”，其危害也来自“问题必须经它解决”。

## 断针与黑客生态

断针不是统一军队，也不具备统一指挥。可分为四类行动者：

1. **数据修复者**：帮客户处理错误记录、找回账户、保存证据，有时越过授权边界。
2. **工具商**：出售 漏洞利用工具、伪造签名、恶意代理组件和匿名服务，通常不问用途。
3. **勒索团伙**：以加密、数据泄露、模型投毒和业务中断牟利。
4. **政治行动者**：泄露公共项目文件、揭露歧视规则或破坏监控，内部对伤害边界争论激烈。

黑客常见线下同伙包括修理铺、二手设备商、跑腿人和物业内部人员。纯远程攻击很难解决所有问题，物理接触、社会工程和合法权限往往更关键。

## 武器与防护

### 常见合法或灰区物品

- 工作刀具、多功能工具和维修切割器；
- 民用防护喷雾、个人报警器和高亮手电；
- 持证保安的约束装备和低功率电击器；
- 工业外骨骼、防撞服和防割手套；
- 用于无人机干扰的专用设备，通常受严格许可限制。

### 枪械

宁洲私人持枪受到严格限制。警方仅部分岗位常规配枪，企业安保和帮派通常不以枪械作为日常装备。非法枪支主要来自老旧走私、沉船或港口黑市，弹药和维护困难。一次枪击会显著提升案件等级，引来刑侦与媒体，不适合作为普通街头冲突的默认结果。

### 网络“武器”

恶意代理、凭证窃取器、数据擦除工具和工业控制器攻击包可造成比实体武器更大的损失，但均有前提：目标系统可访问、权限足够、攻击者理解环境。关键设备常有物理断点，不能用一只终端在数秒内随意接管海堤、地铁和整座医院。

## 冲突升级阶梯

1. **制度施压**：投诉、封禁、评分、停单、合同威胁。
2. **社会施压**：曝光、邻里议论、行业封杀、找家属或雇主。
3. **跟踪与威慑**：盯梢、堵门、展示掌握的隐私。
4. **有限暴力**：推搡、殴打、破坏设备、短时拘禁。
5. **严重犯罪**：枪击、绑架、重大入侵、纵火或破坏公共设施。

玩家每次升级都会改变后续势力的反应。打赢一场冲突可能意味着被企业标记、警方关注或社区不再信任，不能只看当场是否受伤。

## 灾害与紧急状态

台风、海堤告警和大面积网络故障时，海防与应急署拥有最高现场协调权。地铁可能停运，某些区域限制进入，身份核验可能临时改为离线名单。灾害给犯罪分子提供混乱，也让社区互助变得关键。

沉没带最敏感的问题是救援优先级。官方风险模型会优先保护人口密集和资产重要区域，滞留者怀疑自己被刻意放弃。玩家若改变撤离名单或公开真实潮位数据，会影响具体人物的生还与城市政治后果。

## 叙事约束

- 冲突首先服务于人物目标，不为展示武器而存在。
- 企业倾向使用合同、权限和安保程序，不会随便在公众面前杀人。
- 帮派考虑长期生意，不会轻易杀害能引发全面清剿的人。
- 警察内部有程序、派系和个人判断，不作为统一反派。
- 黑客行动必须考虑访问、时间、日志与物理条件。
- 严重暴力会产生医疗、法律、家庭和社区后果，不能一场戏后完全复原。
