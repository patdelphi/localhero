# 临潮市地图、坐标与 POI

## 坐标规范

采用城市平面坐标，用于叙事距离、路线与后续界面，不追求真实测绘精度。

- 原点 `(0.0, 0.0)`：旧城区旧潮位站。
- X 轴向东为正，Y 轴向北为正，单位为公里。
- 坐标指向地点主要公共入口，复杂地点另写内部区域。
- 距离按坐标估算直线距离；实际通勤受道路、门禁、潮位和交通状态影响。
- 区域边界是管理与叙事边界，不是连续高墙；相邻街区常有混合用途。

## 交通骨架

### 地铁

- **一号线**：老港区—旧城区—蜂巢换乘枢纽（HC-06）—云顶区。旧城区站不单列地点编号，蜂巢站的详细结构见 HC-06。
- **四号线**：云顶区—蜂巢区—沉没带北侧。沉没带以南段在 2048 年停运。
- **九号线旧南段**：曾连接旧城区与东南填海区，现仅北段运行；`SM-02` 为废弃南段车站。

### 道路与步行

- **临潮大道**：老港区至蜂巢区的东西主干路，经过旧城北缘，货车与公交密集。
- **骑楼主街**：旧城区南北向商业街，窄、遮雨、人流密集，无人车经常需要人工接管。
- **蜂巢生活环**：连接住宅、学校、商业体和换乘站的有顶步行系统，部分入口受门禁管理。
- **云顶后勤廊道**：供员工、货运与清洁人员使用，与访客入口分离。
- **南堤检修路**：旧城区通往沉没带的低潮路线，高潮或告警时关闭。

## 空间关系与调查价值

- 事务所、诊所、修理铺和小馆步行可达，日常帮助可以自然发生，也令一次封锁或拆迁同时影响多人。
- 栖光里、七号楼、工程调度点和换乘枢纽距离很近，物业调度会影响劳动、交通与商业，不需要夸张的全城入侵。
- 云顶各机构邻近但权限不互通。玩家进入衡宇塔不代表能直接查阅同舟或运行中心资料。
- 老港区工人宿舍与白绳货运场相邻，使班组互助和灰色货运共享人际关系。
- 沉没带南堤、废站和旧数据交换站形成一条物理证据路线；潮位与道路状态会改变可接近性。
- 旧潮位站、海神庙、无名单纪念点和南堤旧闸共同保存 2048 年灾难的不同记忆，适合多路径调查。

## 地图叙事规则

1. 坐标用于建立稳定空间，不把游戏变成精确战术模拟。
2. 移动消耗时间与机会；重要变化通过班次、门禁、天气和人物行程体现。
3. 首版只开放旧城区和蜂巢区，其余 POI 可用于传闻、通信、资料与背景，不提前提供完整场景内容。
4. 任何秘密通道都必须有现实用途和维护者，不能为调查方便凭空出现。
5. 复杂场所至少存在公共入口、后勤入口和应急通道，三者由不同人员与规则控制。
