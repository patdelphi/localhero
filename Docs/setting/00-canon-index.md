# 《灰区事务所》正典导航

## 文档性质

本目录是《灰区事务所》的原创设定圣经。它服务于案件写作、人物表演、空间设计和后续系统研发，不是玩家开局即可全部阅读的城市百科。除“18-gm-secrets.md”外，各文档主要记录公开常识、可调查资料与创作约束；案件幕后真相只收录于主持人秘密文档。

## 不可动摇的共同前提

- 当前时间为宁洲共和国历 2060 年，故事主舞台为临潮市。
- 现实技术已经向前发展四十年。专用人工智能、智能代理、机器人和自动化设备普遍应用，但没有公认成熟的通用人工智能、数字人格、意识上传或记忆编辑技术。
- AI 能写作、诊断、调度、谈判、生成证据般的逼真内容，也能在授权范围内连续执行任务；它们并不因此天然理解公平、责任或人的处境。
- 大多数 AI 并非独立行动者。它们属于企业、政府、平台或私人用户，其目标、训练数据、权限和免责条款决定了它们如何伤人或助人。
- 自动化已消灭大量稳定职业，同时制造审核、标注、维修、申诉、数据清洁等低薪工作。贫富差距和职业不安全是社会常态，而非一场尚未来临的危机。
- 数字身份“宁证”连接工作、金融、医疗、住房与出行。身份异常不等于肉体死亡，却足以让一个人无法正常生活。
- 城市不是废墟。菜市场、家庭饭局、社区婚礼、旧楼维修、夜间小吃和孩子上学仍在继续。人们并非每天反抗体制，更多时候是在体制内寻找可生活的缝隙。
- 首版可玩范围为旧城区与蜂巢区；云顶区、老港区、沉没带作为可抵达的背景区域和后续内容存在。
- 持续角色为一名同伴与十二名主要 NPC，另有半自定义主人公和五名在首批案件中具有独立作用的具名配角；首批三宗案件共用同一批人物和制度矛盾。

## 正典优先级

发生冲突时，按以下顺序修订低优先级文本，而不是并行保留两种解释：

1. 本文件的共同前提与技术边界。
2. 历史年表中的公共日期、城市地理和已公开制度。
3. 人物文档中的出生年份、职业与公开关系。
4. 地图文档中的坐标、道路和地点归属。
5. 主持人秘密中的真实事件；它可以证明公开资料错误，但不能令公开资料从未存在。
6. 媒体、广告、传闻和人物说法；这些内容允许片面、过时或故意撒谎。

## 主要组织速查

- **衡宇系统**：城市算法、政务模型、身份基础设施和企业智能代理供应商。
- **安澜置业**：保障房运营、商业物业和城市更新企业，管理蜂巢区大量住宅。
- **循光自动化**：港口机器人、工业设备和自动配送系统制造商。
- **澜生医工**：医疗器械、工业义体和维护服务商。
- **同舟保险**：覆盖劳动、医疗、设备与身份风险的综合保险公司。
- **白绳会**：旧城区以货运、看守和“调解”为生的地方性组织，介于互助网络与犯罪团伙之间。
- **断针**：松散的黑客与反算法行动者称呼，没有统一领袖和共同政治纲领。
- **零工互助会**：配送员、护理员、清洁工和临时审核员组成的自助组织，不是拥有完整集体谈判权的传统工会。
- **潮声日报**：临潮主流都市媒体，与企业广告和市政信息渠道关系密切。
- **折线**：规模很小的独立调查媒体，靠订阅、捐赠和卖资料维持。

## 内容编号

- 区域：YT 云顶区、LG 老港区、HC 蜂巢区、OC 旧城区、SM 沉没带。
- 地点：区域缩写加序号，例如“OC-01”为灰区事务所。
- 人物：P00 为半自定义主人公，P01—P13 为一名同伴与十二名持续 NPC，其中 P01 为唐葵；S01—S05 为具名配角，不计入十二名持续 NPC。
- 首批案件：C01《不存在的人》、C02《最后一班配送》、C03《潮位线以下》。

## 阅读顺序

### 城市与案件作者

依次阅读 00、01、02、03、04、05、08、09、10、11，再阅读区域地点和 18。这样可先理解制度，再判断人物为什么这样做，避免把结构性矛盾简化成单个坏人的阴谋。

### 叙事与对白作者

先读 07、09、10、15、16、19，再按场景阅读地点文档。人物说出的内容必须受其知识范围、利益和说话习惯限制。

### 主持人

公共资料之外必须阅读 17 与 18。传闻可以错误，证据必须来自既定事实；主持人的职责不是守住预设结局，而是守住事实、人物动机和后果。

## 写作约束

1. 不用“AI 觉醒了”解释本可由产权、指标、腐败或疏忽解释的事件。
2. 不让一次黑客入侵随意控制整座城市。不同系统具有权限隔离、物理断点、审计日志和不同运营者。
3. 技术故障必须影响具体生活：一班电梯、一份保险、一次开门权限、一笔工资或一个无法被证明的身份。
4. 穷人并非永远善良，企业职员并非统一冷血，官员和警察也有不同的利益、专业伦理与家庭压力。
5. 每个主要地点都应能回答“谁在这里谋生、谁付租金、谁承担维护、谁被挡在门外”。
6. 每宗案件至少保留两条发现核心事实的路径，真相可来自人物、物证、记录或空间，不依赖某个唯一设备或 NPC。
