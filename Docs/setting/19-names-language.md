# 命名、称谓、俚语与文本风格

## 命名原则

临潮的名字应像真实城市长期生长出来的结果：有旧地理、有工程编号、有企业营销，也有居民自己改掉的名字。避免所有地点都使用冷酷、夸张或带明显反乌托邦暗示的词。

## 人名规则

### 通用姓名

宁洲姓名以两字姓名为常见形式之一，也有三字姓名和复姓。姓氏保持普通、稳定，名字可反映出生年代和家庭文化，不为每个角色设计象征性名字。

- 老一代：魏淑珍、许春兰、范国安、陈秀梅。
- 中生代：林砚舟、罗启明、陈槐、顾北庭、沈见微。
- 年轻代：唐葵、周弥、方笙、韩鹭、乔稚。

主要人物的名字不必解释成命运预告。梁九是长期使用的绰号，本名梁修衡；只有正式文件、妹妹生气或警方询问时使用本名。

### 昵称与称谓

- 熟人用姓氏加身份：林医生、陈老师、顾工、罗警官。
- 商户与社区用亲切称谓：春兰姐、魏楼长、梁九、惠姐。
- 平台劳动者常用姓氏或群昵称，不随便公开真实姓名。
- 云顶职场偏好姓名加职位，不熟时不用“哥”“姐”套近乎。
- 旧城区孩子可叫年长邻居“婆婆”“伯”，但不等于亲属。
- 对灰档者不要主动用“黑户”，该词带明显贬义。

## 地点命名

### 旧地理

潮平市场、旧潮位站、南堤、临潮河、海神庙、白鹭滞留区，来自水文、产业和社区历史。此类名字使用时间长，官方与民间通常一致。

### 居住与商业营销

云顶、栖光里、新栖公寓、蜂巢安居工程，由开发商和政府项目命名。居民会简称或改写：“栖光里”可指综合体，也可泛指周边生活圈，需要根据语境区分。

### 编号

港口闸口、楼栋、设备与线路使用编号。编号反映管理逻辑，不意味着居民没有感情。蜂巢七号楼既是行政对象，也是住户的家。

### 灰区称呼

沉没带最初是媒体与居民的称呼，后来被非正式公告采用。灰区不是行政分区，而是对正式服务例外的统称。断电工坊是韩鹭自己取的名字，带有她对“先断网再谈”的偏好。

## 企业与组织命名

- 衡宇、安澜、循光、澜生、同舟：企业名称强调稳定、技术、安全或共同发展，与其实际争议形成自然反差。
- 数澜服务：小型数据外包商，名称像许多同类供应商，不应听起来像秘密犯罪组织。
- 白绳会：来自可识别的货运互助标记，名字有具体物质来源。
- 断针：行动者署名，意为拆开缝合处、露出线头，不是正式注册组织。
- 折线：独立媒体名称，表示拒绝把复杂现实压成一条平滑增长曲线。

## 通用俚语

| 词语 | 含义与语气 | 示例 |
|---|---|---|
| 过系统 | 提交自动流程，不代表办成 | “先过系统，过了再找真人。” |
| 找真人 | 寻找有权限且愿意负责的人 | “别跟提示吵，找真人。” |
| 被算了 | 被模型评分、定价或风控不利处理 | “我没违约，就是住的地方被算了。” |
| 灰档 | 各类身份或账户受限的俗称 | “卡还在，人进灰档了。” |
| 热修 | 临时恢复功能，不根治 | “今晚先热修，明天再查源头。” |
| 降级 | 功能被限制，也可指个人生活选择减少 | “门禁降级了，访客进不来。” |
| 挂账 | 赊账或欠人情 | “这碗先挂着，不急着还。” |
| 挂碗 | 春兰小馆预留饭或饭账 | “给夜班那只碗挂上。” |
| 留白绳 | 表示白绳会关注，可指保护或威胁 | “这车不用锁，上面留了白绳。”语境决定含义 |
| 被合并 | 不同问题被系统归为一个，或人被忽略 | “我的工伤和身份被合并了。” |
| 橡皮人 | 只盖章、不做实质复核的人，带贬义 | “窗口是真人，可惜是个橡皮人。” |
| 跑空 | 白跑一趟，也可指代理执行没有结果 | “排两小时，又跑空。” |
| 上岸 | 获得稳定合同、恢复身份或搬离危险区域 | “她以为进衡宇就算上岸。” |
| 下水 | 接灰单、进入沉没带或承担不体面风险 | “他以前不下水的。” |
| 堤内 | 有可靠公共防护，也指制度内安全 | “至少孩子住在堤内。” |
| 留白 | 故意不在记录中写某些信息，可能保护也可能推责 | “这份名单留白了。” |

## 行业黑话

### 数据清洁与外包

- **洗量**：把原始数据快速处理成可交付数量，可能重数量轻质量。
- **吃异常**：由人工处理模型无法判断的记录。
- **回炉**：项目被打回重做，通常不另计全部工时。
- **养号**：维护一个看似正常、可长期使用的生产或平台账户。
- **共享产线**：多人共用生产账户的做法，内部用中性词掩饰违规。
- **清名单**：既可能指删除重复项，也可能指把某些人从项目中排除，需看语境。

### 配送与平台

- **掐点**：按系统计时完成关键节点。
- **压线**：路线或评分接近处罚阈值。
- **吃停留**：异常停留被记为个人责任。
- **放空**：系统派了没有实际订单或无法完成的行程。
- **保号**：优先避免封号，而不是争取最高收入。
- **夜班真人**：强调有人实际处理异常，而非宣传中的全自动。

### 维修与物业

- **旁一下**：临时使用机械或手动旁路。
- **带病跑**：设备有故障仍维持工作，通常暗含管理压力。
- **许可锁**：功能被软件授权而非物理能力限制。
- **白件**：来源与授权清楚的配件。
- **黑盒件**：来源不明的拆件或模块，不必然恶意。
- **热插人**：把没有充分培训的人临时补进岗位，老港区带讽刺意味。

### 警务、法律与调查

- **补链**：补齐证据来源和经手过程。
- **落纸**：把口头承诺变成书面材料。
- **见人**：约到有实际权限的人，不一定指见面本身。
- **压件**：让材料停留在某环节不继续处理，也可指合理暂缓。
- **能立**：达到正式立案或受理门槛。
- **洗白记录**：把本来非法取得的材料通过合法来源重新固定，不代表原始违法行为消失。

## 临潮方言的使用

不要求玩家理解完整方言，用文字体现语气与少量词汇即可。年长居民、港口工人和旧城区店主在熟人场合使用更多，正式场合切回标准语。

可少量使用：

- **“食未”**：吃过没有，常用于关心，不是真的只问吃饭。
- **“莫急”**：先别急，可用于安抚，也可用于拖延。
- **“有影无”**：是不是真的，带怀疑。
- **“相帮”**：互相帮忙，比“合作”更有人情含义。
- **“汰过”**：清理、处理过，具体指数据还是物品看语境。

方言不应用于制造笑料，也不要让所有老人都用同一种句子和口音。语音识别误解应发生在关键生活场景，而非随机添加错误。

## 多语言环境

港口船员、移民和外国客户使用多种语言。通用翻译代理能处理标准对话，对方言、专业责任和情绪暗示仍可能出错。重要合同需要专业翻译或双方确认，不应让终端翻译自动解决跨文化冲突。

外籍与流动人口可能拥有不同身份凭证，不等于灰档。宁洲本地人对他们的态度从友好、依赖到排斥都有，避免用一个群体代表所有外来者。

## 侮辱与冲突用语

角色可以粗鲁，但侮辱应有关系与场景依据：

- “你只会过系统”指责一个人不愿承担判断。
- “堤内人”可讽刺不知基层风险，也可能是羡慕。
- “橡皮人”针对复核失职，不应成为所有公务员的标签。
- “白绳狗”会立即激化与组织成员冲突。
- “断针”被媒体当罪名使用时，韩鹭会纠正具体行为与组织标签的区别。

避免用现实受保护特征作为主要笑料，不把贫困、精神疾病、义体或口音本身写成低劣。

## 不同人物的文本风格

- **唐葵**：先事实、后判断，常用时间和数量；情绪越重句子越短。
- **林砚舟**：具体问身体和需求，少说抽象制度；不会用长演讲表现善良。
- **许春兰**：家常、食物和账目并用，能从闲聊突然切到关键条件。
- **梁九**：零件、故障和维修比喻，技术准确，不擅长安慰。
- **罗启明**：先控制现场，再谈责任；使用“谁看见”“人去哪了”等实际问题。
- **陈槐**：条款、程序和选择后果明确，偶尔过度把人物当案例。
- **魏淑珍**：纠正措辞，引用家庭旧事，温柔中带权威。
- **周弥**：班次、路线、金额，语速快；真正组织动员时反而简短。
- **方笙**：技术确定、自我表述犹疑，避免让她所有台词都怯懦。
- **顾北庭**：先说限制，再说能做什么；不要每次都用同一句口头禅。
- **韩鹭**：反问、俏皮和技术细节交替，严肃时不玩梗。
- **乔稚**：用问题帮助对方表达，不替孩子或家长下结论。
- **沈见微**：有顺序的问题、有限披露、几乎不用无意义寒暄。

## AI 生成内容的文内风格

文内由商业代理生成的公告通常语气平滑、避免绝对承诺、使用“为您”“建议您”“当前暂不支持”等措辞。人工写的社区公告更具体，会有名字、时间、错别字和情绪。

不要让所有 AI 文本都有同一种怪异腔调。高质量模型能模仿自然人，识别伪造应依靠来源链、内容矛盾和现场证据，而不是靠“它用了某个词所以一定是 AI”。

## 城市文本的写作禁忌

- 不连续使用“霓虹、雨水、钢铁、巨物”等视觉套话代替具体生活。
- 不让每条广告都直接暴露企业邪恶；真正有效的广告会回应真实需求。
- 不让所有底层人物都说哲理金句。
- 不把专业名词堆成技术权威，角色应能解释它影响什么。
- 不用“主机”“总控”“核心 AI”作为万能目标，除非明确其有限功能。
- 不用“系统显示不存在”替代全部调查，系统能显示什么取决于账户和数据范围。
- 不用全大写、乱码和故障字表现每次技术异常；多数故障只是普通提示和无人负责。

## 叙事语气

叙事保持克制、具体、有物理细节。优先写“物业把夜间电梯从四部减到一部”，再写人物如何反应，不急着总结“技术正在吞噬人性”。黑色幽默来自人物应对生活的办法，不来自主持人嘲笑受害者。
