# 主要人物：主人公、同伴、持续 NPC 与具名配角

## 使用说明

人物公开档案包含主持人需要掌握的背景、浅层秘密和可演化动机；首批案件的具体幕后真相见“18-gm-secrets.md”。人物不会因为玩家需要线索就出现，也不会自动知道与自己无关的事实。年龄均按 2060 年生日已过的简化口径记录。

P00 是玩家主人公，采用半自定义方式：固定事务所负责人身份、核心处境和共同历史，姓名、性别、外貌与前史可调整。P01—P13 是一名固定同伴与十二名持续 NPC。S01—S05 是在关系网或首批案件中具有独立作用的具名配角，不计入首版十二名持续 NPC。

## P00 江逢：灰区事务所负责人（默认主人公）

- **自定义边界**：江逢为默认姓名，默认 32 岁；姓名、性别、面容和称谓可由玩家修改。以下共同经历、债务与事务所处境属于开局正史，不因外观调整而改变。
- **默认外貌与举止**：身高约一米七，黑色短发，右手虎口有一道旧割伤；习惯把纸质回执按日期夹在终端保护套里。与人谈话时不急着填满沉默，但会不自觉观察对方是否在看出口。
- **身份与住处**：灰区事务所登记负责人，住在事务所同栋后楼的一间小屋。生活半径包括永安里、春兰小馆、青苔诊所和潮平市场，对蜂巢区则主要来自委托与唐葵介绍。
- **共同经历**：在旧城区长大，十八岁离开临潮读书，后因家庭照护和工作多次往返老港区、蜂巢区与云顶区。二十多岁开始接触民事调查、异常工单和身份争议，逐渐学会一件事：机构档案里的“已解决”与当事人的生活恢复正常不是一回事。2059 年灰档事件后回到旧城区，租下 OC-01 并登记事务所。
- **默认前史**：曾在同舟保险担任外勤理赔调查员，负责核对事故现场、身份材料和客户陈述。一次工伤拒赔中，他找到足以支持客户的证据，却在主管要求下把报告写成“事实链不足”。客户后来接受小额和解，江逢则辞职。这段经历可用其他前史替换。
- **经济来源**：寻人、民事调查、资料修复、调解与企业外包委托。收入不稳定，拒绝委托与免费帮忙都会实际影响事务所。
- **固定现实压力**：事务所月租 2800 宁元，开业设备仍有 14000 宁元分期，每月还款约 780 宁元；许春兰为 5600 宁元押金提供担保，因此玩家欠她的不是一顿能还清的饭。
- **擅长**：默认具备洞察与共情，能整理复杂叙述、核对证据来源、让委托人说出难以启齿的部分。其他前史可改为技术或行动倾向。
- **短板**：习惯先处理问题再处理情绪，容易把自己的选择解释为“没有别的办法”；面对穷人委托与企业付费委托时，必须真正决定收费标准，而非靠抽象善良免除压力。
- **当前目标**：让事务所撑过第一年，建立不依附企业、警方或白绳会的可信名声，并弄清自己愿意为什么样的真相承担代价。
- **深层动机**：希望证明“找到一个能负责的人”不该只属于富人，也不愿承认有时自己只是想补偿曾经签过的那份拒赔报告。
- **恐惧**：事务所最终只能靠出卖弱者信息维持；或者自己为了守住道德清白，拒绝所有脏活，却让求助者再也找不到别人。
- **不愿公开的经历**：默认前史中仍保存那次拒赔调查的个人工作笔记。笔记能证明公司曾忽略证据，也证明江逢当时没有坚持到底。
- **与唐葵的合作**：两人在 2059 年一宗身份争议中相识。唐葵提供过合法工作范围内的流程解释，江逢则没有向委托企业透露她的姓名。双方因此建立最初信任，但不是无条件的知己：唐葵反对为了房租牺牲委托人，江逢必须考虑两人的实际生计。感情与亲密程度由后续游玩形成，不预设恋爱。
- **与既有角色的关系**：许春兰是押金担保人和最初的社区介绍者；罗启明认可其调查能力，却担心私人调查把灰色行为正当化；陈槐愿意合作，但会追问证据来源；沈见微把江逢视为难以预测的外部变量。
- **说话方式**：默认表达克制，常用“这件事谁愿意负责”“先说你现在最需要什么”。玩家可自由改变语气，系统不把默认台词当作强制人格。
- **日常事务**：每月处理房租与设备分期，给许春兰介绍来的居民做初步咨询，与唐葵核对案件板，偶尔替魏淑珍把纸质清册做成可检索副本。
- **个人剧情钩子**：旧雇主可能提出一份足以支付数月房租的企业调查合同，目标却是江逢曾经帮助过的人；那份拒赔笔记也可能被陈槐或同舟分别索取。

### 可选前史替换

前史替换只改变进入事务所前的职业、两项倾向和部分熟人，不改变事务所、债务、唐葵合作及三宗案件的固定事实。

| 前史 | 倾向 | 既有关系与额外矛盾 |
|---|---|---|
| 同舟外勤理赔调查员（默认） | 洞察、共情 | 熟悉陈槐与许蓝的职业世界；保存一份能自证也曾伤人的拒赔笔记 |
| 老港区设备安全员 | 技术、行动 | 与梁九、唐葵父亲相熟；曾因服从停工指标而被班组认为站错边 |
| 蜂巢物业客服复核员 | 共情、技术 | 与顾北庭、乔稚相识；曾把一起权限投诉标成已解决，实际只关闭了工单 |
| 折线特约调查撰稿人 | 洞察、技术 | 与陈槐及独立媒体有旧合作；一篇报道因来源保护不足令线人失去工作 |

## P01 唐葵：不愿再替系统推责的同伴

- **年龄与身份**：29 岁，前衡宇外包调度审核员，灰区事务所同伴。
- **外貌与举止**：短黑发，右手常缠一条旧护腕；站着时习惯侧半步，让人能同时看到出口和她。衣服实用，终端贴着一张已经褪色的港口贴纸。
- **经历**：生于老港区工人家庭，父亲在自动化裁员后做零散货运。唐葵靠职业培训进入衡宇外包团队，负责审查配送代理的异常决定。她曾以为保留日志就能让错误被纠正，2059 年灰档事件中发现大量申诉被自动合并关闭，愤而离职。
- **经济来源**：事务所分成、零散数据整理和旧同事介绍的审计私活。
- **擅长**：理解调度与平台记录、发现日志缺口、和基层职员谈判、在压力下拆解任务。
- **短板**：容易把工作关系理解为责任合同，不擅长安慰没有解决方案的悲伤；对衡宇相关问题有明显情绪。
- **当前目标**：证明离开大平台后仍能靠专业生活，并建立一套不牺牲委托人的调查原则。
- **深层动机**：她希望有人承认当年不是她“审核不力”，而是制度根本不给她救人的权限。
- **恐惧**：自己变成另一个只提醒风险、从不承担后果的人。
- **个人压力**：父亲欠下设备贷，母亲希望她回稳定企业；她与旧外包团队仍有保密协议。
- **不愿公开的经历**：离职前复制过一小段与自己操作有关的申诉统计，不是核心数据库，但足以违反合同。
- **重要关系**：信任梁九的技术判断，与周弥因平台策略常争论；对方笙有保护欲，对沈见微既厌恶又认可其能力。
- **说话方式**：短句，先列事实再谈感受。紧张时会说“先把时间线对上”，生气时反而更客气。
- **日常事务**：每周给父亲送饭，处理两三家小店的账目数字化，不时拒绝旧同事的灰色请求。
- **剧情钩子**：她可能接到前团队的高薪返聘，也可能因旧日志被沈见微找上门；玩家若滥用她的技能而忽视她的立场，她会独自追查自己的案子。

## P02 林砚舟：青苔诊所医生

- **年龄与身份**：46 岁，全科医生，旧城区青苔诊所负责人。
- **外貌与举止**：瘦，头发过早花白，白褂口袋里总有纸质标签笔。与病人说话慢，与拖延急救的人说话极快。
- **经历**：曾在市立医院急诊工作，2048 年“白鹿”台风期间参与救援，之后离开医院开设社区诊所。妻子苏旻是海防工程人员，在台风中去世，他独自抚养现已外地读书的儿子。
- **经济来源**：诊费、社区卫生合同、少量职业体检；对困难病人常赊账。
- **擅长**：创伤与慢病、医疗模型结果辨别、识别义体维护问题、在资源不足时做优先级判断。
- **短板**：过度承担，厌烦行政程序，容易把病人的选择也变成自己的责任。
- **当前目标**：维持诊所，推动灰档患者获得不因身份而中断的急救与慢病服务。
- **深层动机**：他不想再让“名单之外的人”在自己的眼前被延误。
- **恐惧**：失去执照后，诊所依赖他的居民连最后的窗口也没有。
- **个人压力**：诊所欠两个月设备维护费，儿子希望他关掉诊所搬去内地。
- **不愿公开的经历**：保存着一批未完整登记的治疗记录，其中包含无法证明身份者和不愿被保险公司知道病情的人。
- **重要关系**：信任梁九维修医疗设备，与罗启明因先救人还是先报案反复冲突；许春兰每天给他留饭，陈槐帮他处理执业风险。
- **说话方式**：先问最实际的问题——“疼了多久”“今天吃过没有”。不说空泛安慰，反感别人用“数据上”开头。
- **剧情钩子**：一名患者的治疗记录可能证明身份错误，也会暴露诊所违规；林医生会要求玩家先保护患者，再谈真相。

## P03 许春兰：春兰小馆老板

- **年龄与身份**：58 岁，旧城区餐馆经营者、商户联席会发起人之一。
- **外貌与举止**：个子不高，卷发用夹子固定，围裙干净但边角磨损。能一边算账一边听完整场争吵。
- **经历**：年轻时在老港区食堂工作，丈夫因工伤去世后，用补偿金盘下小馆。她经历过 2043 年占位抗议，知道居民口号与最后合同可能完全不同。
- **经济来源**：餐馆、夜班订餐和节庆酒席；账面现金经常紧张。
- **擅长**：记住人的习惯与关系、判断街谈真假、组织商户、用一顿饭让对立双方坐下。
- **短板**：太相信自己能调解，遇到女儿相关问题会失去分寸。
- **当前目标**：让更新方案承认老店的经营价值，争取可负担的原地回迁。
- **深层动机**：小馆是她丈夫去世后重新建立的生活，不只是可补偿的营业面积。
- **恐惧**：老街被拆后，大家虽得到补偿，却再也没有见面的理由。
- **个人压力**：白绳会协调费上涨，女儿许蓝在同舟保险工作，认为母亲应当拿钱退休。
- **不愿公开的经历**：2043 年她曾替部分商户代签谈判授权，事后有人认为自己被她代表得过多。
- **重要关系**：照顾林砚舟和魏淑珍，依赖梁九修设备；对罗启明又熟又防，欣赏唐葵但担心她把事情闹大。
- **说话方式**：用食物和家常开场，关键处很直接：“饭要吃，字也要看清。”
- **剧情钩子**：她会在集体利益与个别熟客之间做艰难选择；玩家若绕过她组织居民，可能得到更自由但也更分裂的行动。

## P04 梁九：旧城区维修师

- **年龄与身份**：35 岁，九号修理铺老板，本名梁修衡，熟人只叫梁九。
- **外貌与举止**：左前臂为工业辅助义体，袖口总卷到接口下方；讲话时喜欢把坏零件摆成一排。
- **经历**：曾是循光外包设备技师，因拒绝把一次人为调低安全阈值写成操作员失误而离职。后来到旧城区开店，修理家电、终端、配送设备与合法范围内的义体。
- **经济来源**：维修费、翻新设备、企业不愿公开承认的外包故障分析。
- **擅长**：机械与接口诊断、恢复本地日志、判断零件来源、制作临时旁路。
- **短板**：对物理问题耐心，对人际暗示迟钝；容易收藏“以后有用”的危险零件。
- **当前目标**：取得稳定的第三方医工维修资质，让妹妹不必替他还店铺债。
- **深层动机**：证明修理不是落后的替代方案，而是让人保有选择的技术。
- **恐惧**：自己的热修造成重伤，或店里某个来路不明模块伤害客户。
- **个人压力**：厂商授权费高，店里有一批被扣押的争议配件。
- **不愿公开的经历**：保留客户设备的故障副本，用于交叉判断批次问题；没有出售，但未全部取得明确授权。
- **重要关系**：与唐葵互相尊重，常替林砚舟免费做紧急维修；韩鹭带来的软件让他好奇又警惕，罗启明认为他知道的比说的多。
- **说话方式**：用机器作比喻但不喜欢玄学：“它不是坏，是有人让它只能这样。”
- **剧情钩子**：他可能提供设备真相，也会拒绝为了证据拆坏病人仍在使用的设备。

## P05 罗启明：旧城区社区警察

- **年龄与身份**：52 岁，旧城区派出所警长。
- **外貌与举止**：体格厚实，鞋总是适合走长路的款式；进入店铺会先和在场老人点头。
- **经历**：从巡警做起，2048 年参与沉没带救援，后调到旧城区。他曾相信只要足够熟悉辖区就能减少冲突，近年发现警务模型不断把熟悉的人重新标成风险。
- **经济来源**：公务员工资，收入稳定但女儿教育支出较高。
- **擅长**：现场控制、辨认证词中的关系压力、协调基层部门、判断一场冲突何时会升级。
- **短板**：过度依赖个人经验，对“守规矩就不会有事”仍有残余信念。
- **当前目标**：平稳处理更新期的纠纷，并在退休前培养能接替自己的社区警员。
- **深层动机**：他想证明警察仍可以是具体居民找得到的人，而非模型执行端。
- **恐惧**：自己曾经按流程处理的一件事其实毁了无辜者，而且已无法弥补。
- **个人压力**：上级要求提高风险标记核查率，居民则要求少盘查、多处理真正求助。
- **不愿公开的经历**：长期与白绳会交换有限治安信息，以此减少夜间暴力；没有金钱往来，但界线越来越模糊。
- **重要关系**：信任林砚舟救人，不认可其违规；欣赏陈槐专业能力，厌恶其用媒体施压；视周弥为可能惹事但值得听的年轻人。
- **说话方式**：很少先谈法律条文，常说“你先把人带开”“这件事谁看见”。严肃时叫全名。
- **剧情钩子**：玩家可以让他提前介入，也可能因此让灰色证据和证人进入官方视野。

## P06 陈槐：法律援助律师与人间复核员

- **年龄与身份**：39 岁，执业律师，驻旧城区联合服务点。
- **外貌与举止**：戴普通黑框眼镜，文件夹按颜色分区；疲惫时会反复擦已经很干净的眼镜。
- **经历**：曾在同舟保险外包复核团队工作，负责把自动拒赔转成法律上可接受的文字。看到同一类漏洞反复伤人后辞职，转向劳动、身份与住房援助。
- **经济来源**：公益项目、低收费案件、少量企业合规培训。
- **擅长**：行政复核、证据链、合同漏洞、跨部门材料、把故事变成机构必须受理的问题。
- **短板**：容易把人变成判例，低估公开程序对当事人的私人代价。
- **当前目标**：推动一例能限制“区域风险连坐”的公开裁决，而不只帮单个客户翻案。
- **深层动机**：他想偿还自己曾替拒赔决定润色理由的那几年。
- **恐惧**：发现自己只是让系统更会包装错误，而不是真正改变它。
- **个人压力**：服务点资金将在半年后到期，已有失眠和手部震颤，却不愿减少接案。
