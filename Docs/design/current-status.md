**C01《不存在的人》**，4 个地点：灰区事务所 `OC-01`、新栖公寓 `HC-07`、青苔诊所 `OC-03`、白绳货运场 `LG-05`。

**C02《最后一班配送》**，4 个地点：灰区事务所 `OC-01`、栖光里商业综合体 `HC-01`、零工互助站 `HC-04`、安澜工程调度点 `HC-09`。

已可完整游玩：接受/拒绝委托、自由输入与建议行动、公开 2D6、调查与线索、角色社交链、NPC 计划到期、三种结案、刷新后历史与审计回看、确定性回放校验；C02 另含跨案线索与独立时钟。右侧“城市切片”按行动节拍展示十二名持续 NPC 的公开日程，每行动推进一个时段。历史时间线可从任意已记录行动“从此分叉”，新分支重放该行动之前的历史，原存档保持不变；分支面板支持切换、归档与恢复。

## 4. 已实现能力

- 行动、意图、声明、骰点与提交分离，所有写入走唯一 `commit_action` 事务。
- 结构化事实与 Clock，核心线索不会因单次坏骰永久消失。
- 观察、记忆、证词、玩家假设分型；来源图、holder 隔离与隐私裁剪。
- 记忆精度随时间衰减，诚实误判与追加纠正；旧证词不被回溯改写。
- 公开关系、方向性信任、短期状态、社会记忆与人物履历同源派生。
- NPC 按自身知识视图过滤候选、确定性评分与只读试算；场景导演只排序合法候选。
- 版本 3 审计覆盖候选集、过滤理由、选择结果与认知来源。
- 历史时间线、逐行动机械回放、三态结果与篡改检测。
- 在线模型优先解析合法行动，失败回退本地匹配；叙事失败进入待重试。
- 叙事以固定要点为事实边界，允许补充不改事实的感官细节，不复述要点原句。
- 叙事上下文每回合从已提交事实重建：最近三次行动、当前地点、在场人物、上一条叙事结尾与玩家已知线索；私密认知不进入提示词。
- 在场人物带固定口吻参考；连续叙事以字符 6-gram 相似度检测，超阈值重试一次，仍重复则回退固定要点。
- 上下文按优先级裁剪，默认上限 1200 字符，不影响提交与回放。
- Provider 配置从 `.env` 读取，调用串行、超时与重试有界，日志与健康接口不含密钥。
- 受限情节导演只开放 `environment_complication` 节拍：模型仅能选择固定效果编号，程序校验后写入一条公开事件；默认关闭，可用 `.env`（`AI_DIRECTOR_ENABLED`、`AI_DIRECTOR_INTERVAL`）或界面开关控制。
- 审计 v4 记录触发、提案来源与理由、校验规则和最终效果；被拒绝提案不写事件，接受提案与行动同事务提交并参与确定性回放。
- 案件注册表以 `CaseBundle` 汇总固定内容，C01 内容版本与旧档行为不变；C02 使用独立内容版本、地点、行动链、线索与三种结局。
- 存档按 `games.case_id` 加载案件；新档界面可选择案件，未知编号返回 422。
- C02 跨案线索 `legacy_credential_trace` 关联 C01，公开线索带跨案标记；两案行动、回放与内容版本相互隔离。
- 城市时间以行动条数为节拍，一天四段；十二名持续 NPC 各有固定四段日程，位置面板只展示公开条目。
- 每次行动写入一条有界离屏摘要，进入事件流但不生成玩家认知、不携带事实或隐藏字段。
- 城市切片接口只返回当前时段与公开位置，私密行程（如沈见微）始终裁剪；C01 与 C02 存档均可读取。
- 分支存档从任意已记录行动确定性重放前缀生成，源存档全程只读，分支可继续游玩并独立回放校验。
- `games` 记录父存档、分叉行动与序号、名称、状态和创建时间；直属分支上限 10，分支树单次最多 40 个节点。
- 归档采用软删除，必须显式确认；根存档不能归档，已归档分支可随时恢复，数据完整保留。
- 一键启动脚本支持 `dev` / `prod` 配置档；开发档默认离线，任何配置档都可用 `-Offline` 强制模拟模型。
- 日志写成逐行 JSON 并滚动保留；Provider 统计请求数、最终失败、本地回退与耗时。
- 健康接口只暴露模型来源、离线状态、schema 版本、数据库状态与调用统计，不含密钥、Base URL 或路径。
- 存档支持在线备份、完整性检查、确认式恢复并自动保留安全副本。
- 单存档可导出为 JSON，命令行与 API 均可导入；导入通过确定性重放生成新存档，失败时清理半成品。

## 5. 存档与迁移

- 磁盘数据库使用 WAL 与 `synchronous=NORMAL`，所有变更在事务中提交。
- 真实 `data/games.db` 原为 v2 历史档，已备份（`pre-v3` 至 `pre-v8`）并在 2026-11-06 迁移至 v8；迁移前 SHA-256 `19D49ACD…2083F`，迁移后 `71222A2A…C08A9`，另有独立备份 `data/backups/games-20261106-010743-051408.db`。
- schema v7 为 `games` 增加 `case_id`，升级前自动备份 `pre-v7`；旧档默认 C01。
- schema v8 为 `games` 增加分支元数据，升级前自动备份 `pre-v8`；旧档默认 `branch_status='active'` 且无父存档。
- 旧档认知统一为 `precision='unknown'`，不伪造来源、观察时间或纠正关系。
- 早于回放基线的旧行动返回 `unavailable / baseline_missing`，公开历史仍可查看。
