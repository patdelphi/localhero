# 第八阶段设计：叙事上下文与人物口吻

- 创建日期：2026-11-05
- 状态：实施中
- 依据：[路线图](2026-11-05-roadmap-phase8-13.md)、[当前状态](current-status.md)
- 目标：把单回合叙事扩写升级为跨回合连贯表达，并建立可测试的重复检测与回退机制。

## 1. 设计原则

- 上下文每回合从已提交事实重建，不做跨场景持久“AI 记忆”。
- 只注入白名单字段；隐藏真相、未公开线索、内部评分、人物私密知识一律不进入提示词。
- 模型只表达事实，不改变行动、判定、权限、地点、线索和结局。
- 所有新增能力可关闭、可回退；重复检测失败时回到固定要点。

## 2. 上下文白名单

`app/narrative_context.py` 从数据库事件、案件公开状态和玩家认知派生以下字段：

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| 当前地点 | `case_states.location` | 只取固定名称、区域与固定感官提示 |
| 在场人物 | 地点固定映射 | 只列固定常驻人物，不推断临时到访 |
| 口吻参考 | 固定人物档案 | 仅在场人物，用于动作、神态和已提交回应 |
| 最近行动 | 最近 3 条 `action_committed` | 排除当前行动，只保留行动名称与判定结果 |
| 上一条叙事结尾 | 最近 `narrative_completed` | 只取末尾 120 字，用于衔接语气 |
| 玩家已知线索 | `get_player_knowledge` | 只保留 `visibility=player`，最多 8 条 |

当前行动在提交后才调用叙事，因此上下文中的“最近行动”明确排除当前 `action_id`，避免模型把已发生结果当作新剧情。

## 3. 人物口吻档案

首批档案放在 `NARRATIVE_VOICE_PROFILES`，包含称呼、句长、用词、关注点与禁忌：

- 方笙：短句、谨慎，避免替自己辩解。
- 唐葵：干练、克制，使用事务所行话。
- 林砚舟：专业、审慎，不替患者下结论。
- 苗雨：疲惫、简短，回避承诺。
- 阿洛：口语、直接，不夸张。

口吻只约束表达方式，不授权模型新增台词、决定或人物关系。

## 4. 重复检测与回退

- 归一化后按字符 6-gram 计算 Jaccard 相似度。
- 与最近两条叙事任一相似度超过 `0.35`，视为高度雷同。
- 首次命中后重试一次，温度从 `0.7` 提升到 `0.8`，提示词附“避免复用措辞”。
- 重试仍雷同或返回不可用内容时，回退到该行动的固定要点文本。
- 重复检测只影响文字，不重新解析、掷骰或提交事实。

## 5. 长度上限与裁剪

- 上下文 JSON 上限 `1200` 字符。
- 裁剪优先级：当前地点与在场人物 > 最近行动 > 玩家已知线索 > 上一条叙事结尾 > 口吻参考。
- 超长时从最低优先级字段开始缩短或移除，并记录 `dropped` 列表供测试与日志使用。
- 上下文缺失、事件为空或地点未知时返回稳定空结构，不阻断提交与回放。

## 6. 接入点

- `ProviderModel.narrate(intent, roll, context=None, previous_narratives=None)`：新增可选参数，保持旧调用兼容。
- `SimulatedModel.narrate`：接受相同可选参数但忽略，保持确定性测试。
- `GameService._narrate_or_pending`：提交后读取事件、公开状态和玩家认知，构建上下文与最近叙事，再调用模型。
- 重试叙事仍走同一路径，上下文按当前已提交历史重建。

## 7. 验收测试

- 上下文只包含白名单字段，私密知识与隐藏真相不出现。
- 最近行动最多 3 条且排除当前行动。
- 超长上下文被裁剪且保留地点与最近行动。
- 连续叙事高相似时重试一次；仍相似则回退固定要点。
- 游戏服务确实把上下文与最近叙事传给模型。
- 第七阶段既有契约测试与全量测试保持通过。

## 8. 边界

- 不引入跨场景持久记忆、自由剧情生成或人物自主发言。
- 不让模型读取主持人秘密、内部评分或未公开案件事实。
- 不修改真实存档，自动测试只使用临时数据库。
